1. ファイル読込

PSDをドロップ または ファイルを選択
読み込み中…(大きいファイルは少し時間がかかります)

2. レイヤー

操作のヒント

目のアイコン: 通常レイヤーの表示/非表示。丸印の候補はクリックでプレビューに反映。
候補右の「×」: グループから外して通常レイヤーに戻す。
フォルダ右端の積層アイコン: そのフォルダをグループ化 / 解除。

PSDを読み込むとレイヤーツリーが表示されます。

3. 出力設定
px

ファイル名の付け方

書き出さない差分を外すと、番号は詰めて振り直されます。

0.90
@01.webp

出力例: @01.webp

4. 除外ルール

「目3 と 口2 は同時に使わない」のように、不要な組み合わせを生成前に除外します。

×

PSD読み込み後、使用中の排他グループが2つ以上あると設定できます。

    5. パーツ判定キーワード

    フォルダ名にこの文字を含むとき、指定した種別として扱います(標準の目・眉・口などの判定より優先)。

      使い方

      IKATOOL EXPRESSION EXPORT

      1. PSDを読み込む

      左パネルにPSDをドロップします。ファイルは端末内だけで処理され、外部には送信されません。

      2. グループを自動検出

      候補が並ぶフォルダ(目1/目2/目3など)を排他グループとして検出し、目・口などの種別も判定します。

      3. プレビューで確認

      候補を切り替えて見た目を確認します。通常レイヤーは目のアイコンで表示を切り替えられます。

      4. 除外ルールを決める

      使わない組み合わせを先に登録しておくと、生成枚数を減らせます。

      5. 全組み合わせを生成

      使用するグループから1枚ずつ選んだ全組み合わせを、@01、@02…の連番でWebPにします。

      6. 選んで書き出す

      生成結果から不要なものを外し、ZIPにまとめて保存します。

      プレビュー

      表情グループ

      グループの使い方

      候補を選ぶとプレビューに反映されます。チェックを外したグループは組み合わせに含めず、選択中の1枚に固定します。
      @01は各グループの「通常」(名前に「通常」を含む候補。なければプレビューで選択中の候補)の顔で、以降は通常から変える箇所が少ない順、「その他」種別のグループを変えるものは最後に並びます。
      顔などが消えるときは「グループ解除」か候補の「×」で、不要なレイヤーを外してください。名前とパーツ種別は直接変更できます。

      生成結果

      画像クリックで書き出しの有無を切替。⋮⋮のつまみのドラッグか「‹ ›」で順番を入れ替えられます(連番の並びに反映)。見た目が同じ差分は自動で外し、「重複」と表示します。
